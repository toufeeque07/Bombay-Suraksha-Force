# Bombay Suraksha Force — Static Website

A lightweight frontend website using HTML, CSS, Bootstrap 5 and vanilla JavaScript. No React, Node, database or backend.

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Internet connection is needed for Bootstrap CDN, Bootstrap Icons and Google Fonts.

## Before launch — IMPORTANT
- Confirm the WhatsApp-enabled phone number. Update `WHATSAPP_NUMBER` in `js/script.js` (country code included; no `+` or spaces).
- Add the official Instagram URL in `INSTAGRAM_URL` in `js/script.js`.
- Replace image placeholders with company-approved photos. Keep filenames:
  - `images/hero-security.jpg`
  - `images/team-01.jpg`
  - `images/office.jpg`
  - `images/field-01.jpg`
- Confirm exact service categories and all company claims with the client. Current service cards are draft placeholders.
- Add the official logo image if supplied; current header uses a simple Bootstrap icon mark, not the official logo.
- Test phone, email, WhatsApp and Maps links on mobile.
- The enquiry form only opens WhatsApp with a pre-filled message. It does not save leads or send email automatically.

## Deploy to Vercel
1. Upload/push the folder to a GitHub repository.
2. In Vercel, import the repository.
3. Framework preset: **Other**.
4. Build command: leave blank.
5. Output directory: `.` (root).
6. Deploy.
